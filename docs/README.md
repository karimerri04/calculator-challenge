# Documentation

This directory contains the technical documentation for the calculator challenge.

- `architecture.md` — runtime flow, package boundaries and dependency direction.
- `api-contract.md` — REST request, response and error contract.
- `testing-strategy.md` — backend and frontend verification strategy.
- `frontend-plan.md` — frontend responsibility boundary and API integration.
- `presentation-guide.md` — suggested technical walkthrough for an interview.
- `adr/` — Architecture Decision Records for the principal design choices.
